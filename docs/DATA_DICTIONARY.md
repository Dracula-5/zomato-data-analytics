# Data dictionary

Generated by `make docs` from the dbt manifest and catalog and the schema contracts.
Do not edit by hand. Classification: `public`, `internal`, `pii`, `secret`.

## Sources (raw layer)

### raw.food

Catalogue of food items (dishes) that appear on restaurant menus.

| Column | Type | Classification | Description |
|---|---|---|---|
| f_id | VARCHAR | internal | Food item identifier, e.g. "fd123". |
| item | VARCHAR | public | Dish name as listed on the menu. |
| veg_or_non_veg | VARCHAR | public | Dietary flag, "Veg" or "Non-veg". |

### raw.menu

Which restaurant sells which food item, and at what price (restaurant x food bridge).

| Column | Type | Classification | Description |
|---|---|---|---|
| menu_id | VARCHAR | internal | Menu line identifier. |
| r_id | VARCHAR | internal | Restaurant identifier (references restaurant.id). |
| f_id | VARCHAR | internal | Food item identifier (references food.f_id). |
| cuisine | VARCHAR | public | Cuisine the item is listed under at this restaurant. |
| price | VARCHAR | public | Listed price of the item in INR, as text. |

### raw.restaurant

Restaurants listed on the platform, one row per restaurant. Scraped from a food-delivery site, so most fields are display text and are typed in staging.

| Column | Type | Classification | Description |
|---|---|---|---|
| id | VARCHAR | internal | Restaurant identifier from the source platform. |
| name | VARCHAR | public | Restaurant display name. |
| city | VARCHAR | public | Location as "Area,City" (e.g. "Koramangala,Bangalore") or just "City". |
| rating | VARCHAR | public | Average customer rating 0-5 as text; "--" when there are too few ratings. |
| rating_count | VARCHAR | public | Bucketed number of ratings as text, e.g. "50+ ratings" or "Too Few Ratings". |
| cost | VARCHAR | public | Approximate cost for two as display text, e.g. "₹ 200". |
| cuisine | VARCHAR | public | Comma-separated list of cuisines served. |
| lic_no | VARCHAR | internal | Food-safety (FSSAI) licence number of the business. |
| link | VARCHAR | public | URL of the restaurant page on the source site. |
| address | VARCHAR | public | Street address of the restaurant (a business address; may contain newlines). |
| menu | VARCHAR | internal | Path of the source menu JSON file. The JSON files are not part of the dataset. |

### raw.orders

One row per customer order (SYNTHETIC in this dataset). Machine-generated and clean, so types are enforced strictly at ingestion.

| Column | Type | Classification | Description |
|---|---|---|---|
| order_id | BIGINT | internal | Order identifier. |
| order_timestamp | TIMESTAMP | internal | Local date and time the order was placed. |
| order_date | DATE | internal | Calendar date of order_timestamp; the lake partition key. |
| user_id | BIGINT | internal | Customer who placed the order (references users.user_id). |
| r_id | BIGINT | internal | Restaurant that received the order (references restaurant.id). |
| restaurant_city | VARCHAR | internal | Restaurant location at order time, "Area,City" or "City". |
| cuisine | VARCHAR | internal | Restaurant cuisines at order time, comma-separated. |
| items_count | BIGINT | internal | Number of distinct menu lines in the order. |
| sales_qty | BIGINT | internal | Total units across all lines. |
| subtotal | BIGINT | internal | Sum of line amounts before discount, fees and tax (INR). |
| discount | BIGINT | internal | Discount applied (INR). |
| delivery_fee | BIGINT | internal | Delivery fee charged (INR). |
| gst | BIGINT | internal | Goods and Services Tax (INR), 5% of subtotal. |
| sales_amount | BIGINT | internal | Amount paid = subtotal - discount + delivery_fee + gst (INR). |
| currency | VARCHAR | internal | ISO currency code; always "INR". |
| payment_method | VARCHAR | internal | One of UPI, Card, Wallet, COD, NetBanking. |
| order_status | VARCHAR | internal | One of Delivered, Cancelled, Refunded. |
| customer_rating | DOUBLE | internal | Customer rating 1-5 for delivered orders; empty otherwise. |
| delivery_time_min | DOUBLE | internal | Minutes from order to delivery for delivered orders; empty otherwise. |

### raw.order_items

One row per line of an order (SYNTHETIC). The file has no date, so each line is partitioned by its parent order's order_date, looked up from orders at ingestion.

| Column | Type | Classification | Description |
|---|---|---|---|
| order_item_id | BIGINT | internal | Order line identifier. |
| order_id | BIGINT | internal | Parent order (references orders.order_id). |
| r_id | BIGINT | internal | Restaurant (references restaurant.id). |
| f_id | VARCHAR | internal | Food item (references food.f_id). |
| price | DECIMAL(12,2) | internal | Unit price charged (INR). |
| quantity | BIGINT | internal | Units ordered. |
| line_amount | DECIMAL(12,2) | internal | price x quantity (INR). |

### raw.reviews

Free-text customer reviews (SYNTHETIC; the real file has only 294 distinct comment strings). Partitioned by review date, the day each review arrives.

| Column | Type | Classification | Description |
|---|---|---|---|
| review_id | BIGINT | internal | Review identifier. |
| order_id | BIGINT | internal | Order being reviewed (references orders.order_id). |
| user_id | BIGINT | internal | Reviewer as recorded on the review; may disagree with the order's customer. |
| restaurant_id | BIGINT | internal | Restaurant as recorded on the review; may disagree with the order's restaurant. |
| rating | INTEGER | internal | Star rating 1-5. |
| comment | VARCHAR | internal | Review text written by the customer. |
| review_date | DATE | internal | Date the review was written; the lake partition key. |

*snapshot*. Type-2 slowly changing history of restaurants. When a tracked attribute changes, the old row is closed (dbt_valid_to set) and a new current row is opened, so past orders can be analysed with the attributes that were true at the time.
